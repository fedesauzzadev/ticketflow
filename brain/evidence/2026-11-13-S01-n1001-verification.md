`GET /events` → **16 eventos** con `{id, name, date, price, available}` (snake_case). Incluye los 2 del seed (`evt-mj-tribute-night` 120.50/500, `evt-legacy-tour` 85.00/250) + 14 residuales `it-*` escritos por la corrida de tests (ver §5: son parte de la prueba de AC4). ✓

## 4. H-01 AC2 — invalidación (mecanismo verificado ahora; el disparador de compra es S02)

```
$ curl.exe -s -i -X POST http://localhost:5080/internal/events/evt-mj-tribute-night/invalidate-cache
HTTP/1.1 204 No Content
$ curl.exe -s -i http://localhost:5080/events/evt-mj-tribute-night/availability
HTTP/1.1 200 OK ... X-Cache: MISS        ← el cache fue invalidado, relee del almacén
{"event_id":"evt-mj-tribute-night","available":500}
```
El test de integración `Cache_invalidation_reflects_new_value_from_dynamodb` demuestra el caso completo con mutación real del almacén: MISS(500)→HIT(500)→PutAsync(499)→Invalidate→**MISS con 499**. El endpoint interno es para demos/tests; en S02 el worker que procese reserve/release-seats llama al mismo `AvailabilityService.InvalidateAsync` (in-process, D-0007). ✓

## 5. H-01 AC4 — reinicio del microservicio NO pierde datos (corrida real)

Secuencia (una sesión, comparación cruda byte a byte):
1. `curl GET /events` → 1847 bytes (16 eventos).
2. `Stop-Process` del PID que escucha :5080 (`TicketFlow.Catalog.Api`) — **el emulador no se toca** (verificado Up).
3. Relanzo el servicio (run-local / dotnet run).
4. `curl GET /events` → 1847 bytes → **`-ceq` byte a byte idéntico = True**. 16 eventos.
5. 1ª lectura de disponibilidad del proceso nuevo: `X-Cache: MISS` con `available: 500` (cache fresco, dato vivo del emulador).

Además: los 14 eventos `it-*` visibles en §3 fueron escritos por el PROCESO DE TESTS (~30 min antes) y el servicio recién arrancado los lee — persistencia cross-proceso observada de yapa. El seed es condicional (`attribute_not_exists`): el re-arranque no pisa el estado evolucionado (lo prueba el test `Conditional_seed_does_not_reset_state_on_reinit`). ✓

## 7. Hallazgos de la corrida (registrados en factory/learnings.md)

1. **`pwsh` NO está instalado** en la máquina (solo Windows PowerShell 5.1) — `run-local.ps1` es compatible con ambos (verificado con 5.1). El comando `run` de config.yaml dice `pwsh ./scripts/run-local.ps1`: en esta máquina debe usarse `powershell -File` (o instalar PS7). Decisión pendiente del TL.
2. `dotnet new sln` en SDK 10 genera `.slnx` por defecto → recreado con `--format sln` para respetar los comandos estampados (`TicketFlow.sln`).
3. El emulador devuelve `GetItem.Item = null` (no dict vacío) cuando la key no existe → NRE si se accede `.Count` directo (fix en repositorio).
4. `Microsoft.AspNetCore.Mvc.Testing` 11.0 exige net11 → fijado 10.0.1. `AddHybridCache()` en v11 devuelve `IHybridCacheBuilder` (no encadena `BuildServiceProvider`).
5. PS 5.1 no interactivo: `Invoke-WebRequest` sin `-UseBasicParsing` falla → la evidencia se tomó con `curl.exe`.

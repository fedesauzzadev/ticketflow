## 0) Bug blocker hallado y fixeado en `scripts/run-local.ps1` (camino frío nunca ejercitado)

**Síntoma:** quickstart desde cero (contenedor del emulador DETENIDO) moría en el paso 2:

```
==> Arrancando contenedor aws-emulator existente...
docker : Error response from daemon: Could not find the file
        /home/emulator/.aws/emulator/9297/ca.pem in container aws-emulator
→ exit 1 (NativeCommandError en scripts\run-local.ps1 línea del docker cp)
```

**Diagnóstico (2 intentos):** (1) ensanché la ventana de retry del `docker cp` (20→60) —
falló igual, descartó timing lento del emulador; (2) causa raíz real: en PS 5.1 con
`$ErrorActionPreference='Stop'`, el **stderr de un comando nativo** (`docker cp` mientras
el emulador aún no escribió la CA) lanza `NativeCommandError` terminante y mata el script
ANTES de que el retry loop evalúe `$LASTEXITCODE` — el loop jamás reintentó. En corridas
previas (S01..S03) el emulador ya estaba arriba y `docker cp` nunca fallaba: el camino
frío del script nunca se había corrido.

**Fix verificado:** zona `$ErrorActionPreference='Continue'` alrededor de TODA la sección
docker (ps/start/build/run/cp/exec), restaurada a `Stop` antes del build. Además ventana
de `docker cp` a 60×1 s (el emulador regenera CA+creds al arrancar en frío). Registrado
como **L-009**. Tres corridas del quickstart en frío posteriores: verdes (§1).

run-local. Saga medida POST→primer `TICKETS_ISSUED` observado (poll 100 ms ⇒

**Método (por qué cambió el cliente):** la primera medición con `Invoke-WebRequest` de
PS 5.1 dio p95 GET=331,9 ms / POST=1082,7 ms — inflados por el CLIENTE (auto-detección

(fidelidad del cliente de medición). El bench consumió 51 asientos de
evt-mj-tribute-night (497→446 tras demos; 447→395 tras bench).

**Desvío registrado:** la PRIMERA corrida dio 95/96 — `SagaEndToEndTests…exact_decrement`

pero la invalidación de cache cayó en el otro proceso). Causa ambiental, clase L-008 ya
documentada; con los servicios detenidos: 96/96. **Lección añadida al README (limitaciones):
no correr la suite con el entorno levantado.**

## 7) Desvíos y decisiones

- `run-local.ps1` fixeado (§0): bug blocker del camino frío — no era lógica de servicios.
- `demo-idempotency.ps1`: el caso agotado requiere un evento con ≤7 asientos (drain
  automático); con seeds por defecto hace SKIP con hint. Variante documentada en README.
- Bench temporal fuera del repo (no era entregable del slice); método y números crudos
  acá para reproducirlo.
- Scripts demo: keys únicas por corrida (`Guid`) para tolerar el estado persistente del
  emulador (L-008), y `demo-cache` resetea el cache vía el endpoint interno idempotente
  (documentado en el propio Catalog.Api para demos/tests) para garantizar el primer MISS.

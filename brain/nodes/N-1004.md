# Documentación de portfolio y scripts de demo

Historia H-04 del backlog. El producto ES el portfolio: sin esto el MVP no es
vendible. Traduce el requerimiento literal "Necesito que además esté documentado".

## Alcance
- README raíz: arquitectura (diagrama), decisión de dominio (link a ADR D-0002),
  quickstart copy-paste (emulador + servicios), cómo probar idempotencia y cache.
- `demo-cache` y `demo-idempotency` (scripts .ps1 documentados) que imprimen la
  evidencia de N-1001 y N-1003 en forma legible.
- Mapa de patrones aplicados: patrón → dónde vive (D-0008).

## Implementación (S04)
- `README.md` raíz: qué es + ADR D-0002, diagrama mermaid (base `docs/architecture.md`),
  quickstart (Docker + .NET 10 → `scripts\run-local.ps1`), flujo manual copiable
  (Invoke-RestMethod; curl.exe -d con JSON queda descartado en PS 5.1 por quoting),
  mapa patrón→archivo, verificación con links relativos a evidencias, resumen NFR-5,
  limitaciones del emulador.
- `scripts/demo-cache.ps1` (PS 5.1): reset por endpoint interno idempotente →
  MISS→HIT (mismo valor) → compra real → MISS (valor−1) → HIT del valor nuevo. Exit 0/1.
- `scripts/demo-idempotency.ps1` (PS 5.1): keys únicas por corrida (L-008); replay
  200 misma compra/mismos tickets, disponibilidad delta 0, mismatch body ⇒ 422
  `idempotency-key-reused`, agotado: drain automático del evento con ≤7 asientos o
  SKIP con hint (variante SEED_EVENTS de 1 asiento documentada en README) ⇒ 422
  `seats-unavailable`. Exit 0/1.
- NFR-5 medido en la evidencia (bench temporal, cliente fiel — ver L-010).

## Notas
- Fix blocker incluido: `run-local.ps1` zona EAP 'Continue' para nativos docker
  (camino frío moría en NativeCommandError — L-009). No tocó lógica de servicios.
- Ver desvíos y método de medición en la evidencia S04.

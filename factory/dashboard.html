Bloqueos y aprendizajes

L-001 · SDK v4 → AWS real

RegionEndpoint+ServiceURL manda tráfico a AWS real. Fix: ServiceURL+AuthenticationRegion + TLS pin.

L-002 · SNS sin entrega

SNS→SQS no entrega en el emulador. Fallback: evento interno; re-evaluar V1.

L-003 · pwsh ausente

Solo PS 5.1: scripts y commands.run compatibles 5.1.

L-004 · emulator races

Arranque del emulador con ensure tolerante (carreras de seed/credenciales).

L-005 · CS9107 base-worker

Patrón base-worker para background services sin warning.

L-006 · quoting PS 5.1

curl -d con JSON en PS 5.1 quieera comillas → Invoke-RestMethod / -o NUL.

L-007 · mensaje en limbo

Consumidor muerto → mensaje SQS ~30 s invisible; handlers idempotentes lo toleran; DLQ formal V1.

L-008 · aislamiento de tests

Estado persistente del emulador: keys/colas únicas por corrida; servicios abajo al testear.

L-009 · EAP Stop + docker

stderr de nativos docker mata scripts PS 5.1 en camino frío → zona EAP Continue.

L-010 · medir p95 con HttpClient

Cliente PS 5.1 ruidoso falsea latencias; medir con HttpClient reutilizado.

L-011 · retry SDK multiplica timeout

MaxErrorRetry por defecto → 4×10 s. Fix: MaxErrorRetry=0, retry vive en la app.

L-012 · coverlet condicionado

CollectCoverage solo corre con el target msbuild activo — umbral condicionado a env del emulador.
